# Engineered Quiet — cover design philosophy

**Movement:** Geometric Silence meets Chromatic Language.

Each project cover is a single, precise composition that explains one automation the way an engineering drawing explains a machine: one hero object, one systematic pattern, and almost no words. The covers sit inside a dark, editorial portfolio, so they speak in the same voice: calm, exact, confident. Nothing shouts; the work does.

**Space and form.** A fixed 80px margin and an invisible 12-column grid govern every canvas. Elements never overlap or touch the edge. Large quiet zones are deliberate: they give the hero object room to be looked at. Forms are perfect geometry (circles, rounded rectangles with consistent radii, 1px hairlines) drawn as vectors, never clip art or emoji.

**Color and material.** Each project owns a three-hue palette (a ground, a signal, a light) expressed in tones of those hues only. Color carries meaning: the signal hue marks the moment the automation adds value (a generated ad, an approval, a booking). Light comes from one direction; surfaces get one soft gradient, never several.

**Scale and rhythm.** Hierarchy comes from scale contrast: one large, thin headline (Inter Tight 300) with a single serif-italic accent word, set against tiny monospaced labels. Repetition is the second voice: rows of frames, drafts or slots repeat with small, intentional variations, so the eye reads "many" without being told.

**Composition.** Every cover reads left to right as input → process → output. The process is drawn as a hairline with numbered nodes, the same notation on every cover, so the set feels like one family while each cover's hero object and palette stay distinct.

**Text.** Text is a rare gesture: a headline of at most six words, a few uppercase mono labels naming real steps or real tools, nothing else. No paragraphs, no invented metrics, no garbled filler.
